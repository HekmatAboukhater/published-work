# Published work

[Browse the HTML archive](https://whatthehekmat.github.io/published-work/)

I’ve put my reporting, policy research, translations and podcasts in one place, along with a few projects I’ve published here on GitHub. Each entry links to the work and includes a short note on what I was trying to find out or what I contributed.

The archive lives in [index.html](index.html), which can also be opened locally. To add a piece, copy an article entry into the appropriate year, then update that year’s count in the navigation.
